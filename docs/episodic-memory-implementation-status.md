# Episodic memory: authorization prerequisite only

This change is a partial implementation, not activation of cap_episodic_memory_58. It supplies working canonical JSON serialization, shared inclusive caps, and a fail-closed exact-byte batch authorization boundary. Callback mutation cannot change retained bytes; timeout and late approval are handled independently of any execution deadline. The helper neither persists records nor registers tools.

## Unverified preflight

This contribution environment supplied filenames but no repository contents, shell, or execution tools. Consequently the main SHA, npm ci, baseline/full Vitest logs, and actual AgentRuntime settlement, ToolRegistry, ObservationStore, classifier, inspection-exemption, and Finalizer signatures could not be inspected or published. No passing-CI or runtime-integration claim is made. Tests here exercise only symbols added in this change.

## Remaining implementation

The Episode v1 schema and runtime-owned terminal enums must be derived from inspected runtime signatures, not guessed. Schema validation must precede this authorization helper: canonicalization is not episode validation, provenance validation, or a content-safety check. The authenticated host, not model arguments, must supply principal and authorizer. Invoke authorization only after terminal publication with frozen, completed candidates.

Still required: real injected local filesystem store and exclusive owner lock; bounded checksum-validated reads; exact-byte publication and uncertain-commit reconciliation; quota and retention handling; frozen permission-checked views; deterministic lexical retrieval; runtime settlement projection; tool and recovery integration; inference-destination permission checks; evaluation isolation; and real-loop acceptance tests. No store, runtime option, capability registration, or retrieval tool is introduced by this prerequisite, so it must not be advertised as cross-run memory. No persistence, power-loss durability, orchestration, or retrieval-benefit evidence has yet been obtained.
